    Despliegue de nuestro sitio Hugo en GitHub Pages (PrácticaX2)

    Para publicar nuestro sitio Hugo en GitHub Pages bajo la subruta del repositorio (https://javiperomingo.github.io/mi-sitio-hugo/), hemos aplicado tres ajustes esenciales: Configuración de baseURL y publishDir: En hugo.toml definimos la URL pública final y el directorio de salida para que Hugo genere todas las rutas de forma coherente. Uso de relURL en las plantillas: En los parciales de cabecera y navegación empleamos {{ "css/estilo.css" | relURL }} y {{ .Site.Home.RelPermalink }} para evitar enlaces o estilos rotos al servir la web desde un subdirectorio. Fichero .nojekyll: Añadimos static/.nojekyll para que GitHub Pages sirva directamente el HTML plano generado por Hugo sin procesarlo con Jekyll.

    Ventajas de los generadores de sitios estáticos en IAW

    En el módulo de Implantación de Aplicaciones Web (IAW) buscamos desplegar aplicaciones web de forma simple, segura y robusta. Algunas ventajas clave de usar Hugo frente a gestores de contenido dinámicos tradicionales son: Rendimiento: Al servir HTML plano pregenerado, la respuesta del servidor web es inmediata. Seguridad: No hay base de datos que pueda sufrir inyecciones SQL ni código dinámico ejecutándose en cada petición. Portabilidad y control de versiones: Todo el sitio (configuración, plantillas y contenido en Markdown) vive dentro de un repositorio Git.
