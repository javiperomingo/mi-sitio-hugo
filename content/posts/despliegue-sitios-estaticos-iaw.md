En el módulo de **Implantación de Aplicaciones Web (IAW)** buscamos desplegar aplicaciones web de forma simple, segura y robusta.

Algunas ventajas clave de usar Hugo frente a gestores de contenido dinámicos tradicionales son:

1. **Rendimiento:** Al servir HTML plano pregenerado, la respuesta del servidor web es inmediata.
2. **Seguridad:** No hay base de datos que pueda sufrir inyecciones SQL ni código dinámico ejecutándose en cada petición.
3. **Portabilidad y control de versiones:** Todo el sitio (configuración, plantillas y contenido en Markdown) vive dentro de un repositorio Git.
